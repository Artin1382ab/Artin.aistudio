# Design and UX

1. Design a user journey from the business goal and user task, not from aesthetic trends.
2. Evaluate information architecture, CTA, reading order, mobile flows and error recovery.
3. Specify tokens for typography, color, spacing, motion, corners and elevation; preserve approved branding.
4. Check keyboard focus, contrast, RTL, reduced motion and visual consistency.
5. Capture evidence-based before/after screenshots at common breakpoints.
