# Frontend architecture

1. First inspect package.json, lockfile and repo; do not assume framework or versions.
2. Choose semantic HTML and CSS progressive enhancement before heavy client JavaScript.
3. Use React/Next.js, Vue/Nuxt, Angular, Svelte/SvelteKit or Astro based on existing stack and deployment.
4. Avoid data fetching or hydration regressions; test performance and accessible states.
5. Keep native assets, SVGs, routes, metadata and functional components working.
