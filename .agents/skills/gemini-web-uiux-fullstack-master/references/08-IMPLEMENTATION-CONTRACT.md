# Implementation and acceptance contract

1. Start with inspection and scope map before edits.
2. Never silently change protected links, page URLs, product logos, copy, brand tokens, database schemas or business logic.
3. Maintain a modified-files manifest and commands to reproduce tests.
4. Always label suggestions, generated code, simulated mocks and verified execution separately.
5. Delivery must include impact, rollback, accessibility, performance, responsive and regression status.
