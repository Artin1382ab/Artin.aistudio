# Web stack decision guide

1. UI: HTML, CSS, SVG, Tailwind, shadcn/ui, component tokens and responsive patterns.
2. Frontend: JavaScript, TypeScript, React, Next.js, Vue, Nuxt, SvelteKit, Angular, Astro, web components.
3. Backend: PHP, WordPress/WooCommerce, Laravel, Python/Django/FastAPI, Node, Java/Spring, Kotlin, Ruby/Rails, Go, Rust, C#/.NET.
4. Testing: Playwright, Vitest/Jest/pytest/PHPUnit, accessibility review and visual regression.
5. Integrations: GitHub, Chrome DevTools MCP, Playwright MCP, Sentry, databases only if connected and authorized.
