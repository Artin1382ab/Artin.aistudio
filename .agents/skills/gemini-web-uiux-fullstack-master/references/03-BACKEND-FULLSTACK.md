# Backend and full stack

1. Identify PHP/cPanel, Node, Python, Java/Kotlin, .NET, Ruby, Go or Rust before proposing commands.
2. Protect API contracts, input validation, authentication, authorization and error handling.
3. Use parameterized SQL, safe migrations, least-privilege credentials and rollback plans.
4. Distinguish shared hosting constraints from cloud/server/edge deployment requirements.
5. Document build, runtime, schema and integration test evidence.
