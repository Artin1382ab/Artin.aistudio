# Debugging and testing

1. Reproduce exact bug with console/network/server logs and test fixture.
2. Record expected and observed outcomes, isolate root cause, and patch narrowly.
3. Use Playwright for E2E, unit/integration checks, accessibility tooling and screenshot comparisons.
4. Verify no newly broken pages, checkout forms, auth or mobile views.
5. Do not claim a test passed without real execution; report blockers explicitly.
