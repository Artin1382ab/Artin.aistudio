# UI/UX Pro Max integration

1. Official project: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
2. Local installation: npm install -g ui-ux-pro-max-cli@latest
3. Run uipro init --ai gemini from the target Gemini CLI project or uipro init --ai antigravity in Antigravity workspace.
4. Use uipro update to refresh installed assets; review license and third-party installation before running.
5. This Gemini Apps cloud skill does not include or install third-party UI/UX Pro Max assets; its use is instructional without connected runtime.
