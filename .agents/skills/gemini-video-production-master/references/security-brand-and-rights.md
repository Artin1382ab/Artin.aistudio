# Safety, reproducibility and commercial use

- Strictly non-destructive: never delete or silently modify imported footage; output only to a named staging/output folder.
- Never install executables on a Gemini Tasks cloud environment by merely instructing it to run terminal commands. Ask for an actual connected runtime.
- Sandbox untrusted third-party skills and read every `SKILL.md`/script before copying into globally discoverable paths.
- Respect customer logos, packaging, protected trademarks, actual colors and approved product text; verify every altered composited frame.
- Verify commercial licensing of Remotion use category, model checkpoint terms, voice rights, music sync license, stock footage rights and talent releases.
- Privacy: avoid exposing client files in third-party services without authorization. Do not leak credentials or upload unpublished campaign footage to unapproved endpoints.
- Quality gate: inspect previews and a real final file before writing "rendered" or "completed"; provide checksums and error logs when present.
